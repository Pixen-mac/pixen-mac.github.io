Pixen 6.0

Pixen is the professional pixel art editor for macOS, built for low-resolution raster art like 8-bit game sprites. It delivers a unique color palette system, patterns, layers, high-zoom precision, and intuitive frame-by-frame animation tools—all in a native Mac interface refined for macOS 26 with Liquid Glass support.

Refreshed Design

Updated interface with new icon, controls, and menu icons. Toggle Liquid Glass effects independently for sidebars and toolbars. Hide the layers sidebar to maximize canvas space.

Advanced Palettes

Create, sort, edit, and organize color palettes directly in the document window. Navigate rows with arrow keys. Drag-and-drop reliability improved for seamless workflow.

Precision Tools

Mirror X/Y for symmetrical Pencil drawing. Clone layers to all animation frames. Rotate canvas with new shortcuts. Trim Canvas access streamlined for exact fits.

Animation Power

Frame-by-frame editing with shared backgrounds via layer cloning. Export sequences remember last format and default names. Performance optimized, even on older Macs.

Quality Improvements

Fixed rotation offsets, background picker issues, and export warnings. New shortcuts for Welcome window, color panel, and more. Reliable across macOS versions.

How It Works

1. Start Your Canvas

Open Pixen and set your low-res dimensions. Import palettes or create from scratch for authentic 8-bit vibes.

2. Draw with Precision

Use Pencil with Mirror tools, layers, and patterns. Zoom infinitely. Organize colors inline—no switching windows.

3. Animate Frames

Add frames, clone layers across them. Edit backgrounds once, propagate everywhere. Rotate and trim as needed.

4. Export Seamlessly

Choose formats, remember settings. Drag sequences or sheets. Ready for games, apps, or sharing.
